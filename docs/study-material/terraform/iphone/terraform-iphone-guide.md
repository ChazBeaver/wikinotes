## Transfer the book before your flight

1. Transfer your chosen EPUB files to your iPhone while you have internet access.
2. Use a method you already have, such as iCloud Drive or an email attachment.
3. Save the actual file in Files. Do not save only a link to it.
4. Tap the EPUB to open it in Books.
5. If it opens elsewhere, use the Share menu and select Books. Look under More if necessary.
6. Wait until the book opens and you can read a section.
7. Repeat for each EPUB. Include the cram EPUB for quick review.

For a PDF, use the Share menu and select Books, or open the downloaded file in a PDF reader.
See [Apple's PDF instructions](https://support.apple.com/guide/iphone/read-pdfs-iphab2193d5/ios).

## Check offline access before leaving

1. Keep a local copy of the files under **On My iPhone** in Files.
2. In Books, complete any pending downloads for the imported books.
3. Turn on Airplane Mode.
4. Turn off Wi-Fi too. Airplane Mode can leave Wi-Fi enabled.
5. Open each imported EPUB in Books.
6. In the complete book, open the cram sheet, a code example, and a later chapter from Contents.
7. Open the separate cram EPUB too if you transferred it.

If a file cannot open, reconnect and download it fully. Repeat the offline check.
A cloud listing or thumbnail is not proof that the file is stored on the phone.

## Read comfortably

- Adjust the EPUB font size in Books.
- Use Contents to jump to a topic.
- Use scrolling view if you prefer continuous reading.
- Rotate the phone for more space around code examples.
- Treat wrapped code lines as display wrapping, not new code instructions.

See [Apple's reading controls](https://support.apple.com/guide/iphone/read-books-iphc1af7c57/ios).

## What works without internet?

- All study text, examples, questions, and answers in the EPUB files.
- Each book's contents list, plus links between guides in the complete book.
- The PDF text and its internal contents links.

Links to HashiCorp, Apple, or other websites require internet access.
Those external pages are not included. Cloud exercises also need their normal tools and network access.

These travel files are snapshots. Later edits to the Markdown do not automatically update them.
